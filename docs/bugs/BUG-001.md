# BUG-001 - 2x Interpolation Doubled Output Duration

## Context

The MiniMax H3 workflow added 2x RIFE interpolation to a native 24 FPS video.

## Symptoms

- The 12.25-second source contained 294 frames at 24 FPS.
- RIFE produced 587 frames, but the final video remained at 24 FPS.
- The resulting video was 24.46 seconds while its audio remained 12.25 seconds.

## Root Cause

The FPS math node's single `widgets_values` entry was serialized as a JSON string instead of an array. ComfyUI loaded the intended `a * 2` expression as `a`, leaving output FPS unchanged at 24.

The structural test checked links but did not inspect the JSON value shape or an encoded output.

## Fix

- Remove the fragile FPS expression node.
- Encode the fixed MiniMax 2x interpolation output explicitly at 48 FPS.
- Move RIFE before the 4x RTX spatial upscaler to reduce interpolation work.
