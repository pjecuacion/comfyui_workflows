# BUG-002 - Turbo Audio Crashed SaveVideo

## Context

The dedicated MiniMax H3 Turbo workflow completed generation, audio/video VAE decode, RIFE interpolation, and RTX upscaling before failing in `SaveVideo`.

## Symptoms

- Node 92 (`SaveVideo`) raised `av.error.ValueError` from `avcodec_send_frame()`.
- FFmpeg's AAC encoder reported `Input contains (near) NaN/+-Inf`.
- The render log confirmed that RIFE successfully produced 247 frames before the save failed.

## Root Cause

The generated audio waveform contained non-finite floating-point samples. The workflow passed decoded model audio directly into `CreateVideo`, and AAC rejects NaN and infinity values.

The unrelated TTS Audio Suite import warnings in the same log did not cause this failure.

## Fix

- Add the local `MiniMaxH3AudioFiniteGuard` node.
- Replace NaN with silence, map infinities to the valid peak range, and clamp samples to `[-1, 1]`.
- Place the guard between `VAEDecodeAudio` and `CreateVideo`.
- Preserve normal in-range samples and the original sample rate.
