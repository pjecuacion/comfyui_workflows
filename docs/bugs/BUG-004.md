# BUG-004 - Multishot Turbo Step Value Serialized Into Seed Control

## Context

The first Multishot Turbo AIO workflow was intended to display four sampling steps.

## Symptoms

- `control after generate` displayed `4` instead of `randomize`.
- `steps` remained at the standard value of `20`.

## Root Cause

The builder wrote `4` to widget index 6. The seed's `control_after_generate` value occupies index 6; the sampling step value occupies index 7.

## Fix

Preserve widget index 6 as `randomize` and write the Turbo step value to index 7.

## Tests

The integration test now independently asserts both serialized widget positions.
