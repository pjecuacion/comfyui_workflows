# BUG-005 - README Workflow Table Rendered As One Garbled Row

## Context

The public workflow index is maintained in `docs/README.md`.

## Symptoms

GitHub rendered the workflow table as a long, garbled line instead of three aligned columns.

## Root Cause

The table declared three headers but its Markdown separator row declared only two cells.

## Fix

Added the missing third separator cell so the table has three columns.

## Tests

`tests/bugs/BUG-005-readme-table.test.ps1` checks that the header, separator, and every workflow row have three cells.
