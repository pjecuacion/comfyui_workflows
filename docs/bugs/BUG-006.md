# BUG-006 - MiniMax H3 Latent Upscaler Did Not Use Supplied Audio as the Output Track

## Context

The supplied MiniMax H3 reference-to-video latent-upscaler workflow accepted a `LoadAudio` node but did not make the selected clip the exported MP4 soundtrack.

## Symptoms

- The reference-audio connection reached `MiniMaxH3ReferenceToVideo` only.
- The prompt instructed H3 to use the clip for timbre only and explicitly not reuse its words.
- `CreateVideo` received audio decoded from H3's generated latent instead of the loaded clip.

## Root Cause

Reference audio is conditioning, not an automatic exact soundtrack. The graph lacked an `MiniMaxH3AddGuide` audio anchor and exported the separate generated-audio branch.

## Fix

- Create `workflows/minimax-h3-latent-upscaler/minimax_h3_r2v_latent_upscaler_exact_ref_audio.json` without changing the Downloads source.
- Add `MiniMaxH3AddGuide` at frame 0 so the supplied clip guides speech timing and lip movement in both sampling stages.
- Keep the clip connected to `ref_audio_0`, then connect the same `LoadAudio` output directly to `CreateVideo`.
- Replace the timbre-only sample prompt with an exact-dialogue and timing instruction using `<Audio 1>`.

## Tests Added

- `tests/bugs/BUG-006-minimax-h3-reference-audio.test.ps1`

## Usage Note

Set the duration input to the supplied clip's intended length. H3 renders at 24 FPS and snaps valid frame counts to `17k + 5`; 124 frames is about 5.17 seconds, 243 is about 10.13 seconds, and 362 is about 15.08 seconds.
