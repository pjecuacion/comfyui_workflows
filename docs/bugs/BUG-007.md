# BUG-007: Face-detail workflow imports with `null.replace`

## Context

The face-detail workflow includes the `DualVideoPreview` output node.

## Symptoms

ComfyUI shows `Cannot read properties of null (reading 'replace')` while importing or running the workflow, and a node is marked red.

## Root Cause

`DualVideoPreview` is a normal custom node, but its `widgets_values` were serialized as a named object. ComfyUI restores ordinary node widgets by ordered position. The missing positional value became `null`, and the frontend later called `replace` on it.

## Fix

Serialize the six widget values in input order: `video_1`, `video_2`, `label_1`, `label_2`, `fps`, and `loop`. The graph links and node implementation are unchanged.

## Tests added/updated

- `tests/bugs/BUG-007-face-detail-widget-serialization.test.ps1`

## Lessons

When adding a custom node to a hand-authored workflow, verify its widget serialization against the live `/object_info` input order, including widgets that also have a link.
