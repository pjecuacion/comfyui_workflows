# BUG-007: Face-detail workflow imports with `null.replace`

## Context

The face-detail workflow includes the `DualVideoPreview` output node.

## Symptoms

ComfyUI shows `Cannot read properties of null (reading 'replace')` while importing or running the workflow, and a node is marked red. After the compare node was corrected, the video detailer still showed `cfg: NaN`, an invalid sampler, and an invalid scheduler.

## Root Cause

`DualVideoPreview` was serialized as a named object, and the detailer array omitted ComfyUI's generated `control_after_generate` widget after `seed`. ComfyUI restores ordinary node widgets by ordered position, so every later value shifted into the wrong control and a missing value became `null`.

## Fix

Serialize ordinary widgets as complete ordered arrays. `DualVideoPreview` uses six values in input order. The video detailer includes the generated `control_after_generate` value (`fixed`) between seed and steps, followed by CFG, sampler, scheduler, denoise, feather, refiner ratio, and noise-mask feather. The graph links and node implementations are unchanged.

## Tests added/updated

- `tests/bugs/BUG-007-face-detail-widget-serialization.test.ps1`

## Lessons

When adding a custom node to a hand-authored workflow, verify its widget serialization against the live `/object_info` input order, including widgets that also have a link.
